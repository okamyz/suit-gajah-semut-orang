
# suit-gajah-semut-orang

Ini merupakan permainan simpel suit jadul, dimana player diharuskan memilih antara; gajah, semut, dan orang. Komputer akan memilih random diantara 3 tersebut.  


## Cara pengunaan

 - Menggunakan live server yang dijalankan melalui file index.html pada browser pengguna
 - Akan ada alert dan prompt yang muncul pada halaman browser pengguna 
 - Pengguna cukup mengikuti arahan dari alert dan prompt yang muncul 


## Peraturan Permainan

- Gajah < Semut
- Semut < Orang
- Orang < Gajah
## Challenge

Coba untuk mengalahkan komputer 3 kali berturut-turut
